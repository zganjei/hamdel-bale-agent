# همدل — دستیار ایجنتیک بله

کد اصلی در این مخزن است. مدل، دستورهای ایجنت، ابزارها و تنظیمات صوت با تغییر فایل‌های گیت‌هاب به‌روزرسانی می‌شوند؛ نیازی به ویرایش فایل در پنل لیارا نیست.

## استفاده

در خصوصی @hamdel_report_bot عادی صحبت کن؛ در گروه متصل‌شده منشن یا ریپلای کن. ایجنت آرشیو را جستجو می‌کند، گزارش و فایل CSV/XLSX می‌سازد، درخواست کمک آماده می‌کند و برای پوستر ابزار تصویرسازی را درخواست می‌کند. ثبت مالی در دفتر قطعی به تأیید مدیر نیاز دارد. تلگرام متصل نیست.

## مدل و مصرف

`config.json`: پیش‌فرض `gpt-6-luna` با reasoning برابر `low`، بدون ارتقای خودکار مدل. هر چت سشن جداگانهٔ Codex دارد. کل آرشیو و تاریخچه به هر پیام ضمیمه نمی‌شود؛ ایجنت با ابزار archive فقط منابع مرتبط را می‌خواند. فشرده‌سازی سشن در حدود ۱۸هزار توکن تنظیم شده و مصرف هر نوبت در usage_events ذخیره می‌شود. سشن ادامه‌دار به معنی صفر بودن هزینهٔ تاریخچه یا سهمیهٔ نامحدود نیست.

## صوت فارسی بدون هزینهٔ API جداگانه

مسیر اصلی: **بله → Cloudflare Workers AI (مدل @cf/openai/whisper-large-v3-turbo) → متن فارسی برای تأیید مدیر → Codex**.
ورودی صوتی مستقیم در `codex exec` وجود ندارد. Cloudflare مدل را روی سرور خودش اجرا می‌کند، پس مدل سنگین روی Liara بارگذاری نمی‌شود؛ فقط `ffmpeg` سبک فایل OGG/Opus را به قطعه‌های MP3 تبدیل می‌کند.

این روش فقط با حساب **Workers Free** توصیه شده: طبق سیاست Cloudflare، روزانه ۱۰هزار Neurons رایگان است و پس از تمام‌شدن سهمیه در پلن رایگان درخواست جدید متوقف می‌شود. **پلن Paid فعال نکنید** تا هزینهٔ اضافه ایجاد نشود. دیگر استفاده‌های Workers AI همان حساب نیز از سهمیه کم می‌کنند. کیفیت فارسی روی ویس‌های واقعی همدل هنوز تست نشده است.

برای فعال‌سازی یک‌بار در Secrets مخزن GitHub دو مقدار زیر را ذخیره کنید:
- `CLOUDFLARE_ACCOUNT_ID` — شناسهٔ حساب Cloudflare
- `CLOUDFLARE_API_TOKEN` — توکن محدود به اجرای Workers AI در همان حساب

به‌محض اضافه‌شدن هر دو Secret و اجرای موفق workflow، اسکریپت استقرار مقدارهای قدیمی را در Liara جایگزین می‌کند، یکسان‌بودنشان با GitHub Secrets را بدون افشای مقادیر بررسی می‌کند و از داخل فرایند بات یک تست واقعی Cloudflare انجام می‌دهد (هرگز در کد یا GitHub commit وارد نمی‌شوند). تا قبل از آن، پردازش صوت با یک خطای امن متوقف می‌شود. ویس‌های غیرمخاطب در گروه فقط آرشیو می‌شوند و هرگز خودکار برای تبدیل صوت بیرونی ارسال نمی‌شوند. پیام صوتی و متن مالی پیش از ورود به ایجنت نیاز به تأیید مالک دارند؛ موارد نامفهوم حدس زده نمی‌شوند. فایل صوتی برای پردازش به Cloudflare ارسال می‌شود؛ برای فایل‌های محرمانه باید به سیاست حفظ حریم خصوصی توجه کرد.

تنظیمات در `config.json`: `speech_provider=cloudflare_free`، `speech_max_seconds=600`، `speech_chunk_seconds=26`. صوت تا جای ممکن بر اساس مکث‌های طبیعی تقسیم می‌شود. Codex یک ویرایش نگارشی محتاطانه پیشنهاد می‌دهد (با مصرف سهمیهٔ Codex، بدون API پولی) و متن خام در آرشیو نگه داشته می‌شود و با دکمهٔ «متن خام Whisper» قابل مشاهده است. این کار نمی‌تواند خطای شنیداری را تضمینی رفع کند. مسیرهای قدیمی `whisper_cpp` و `http` همچنان نگه داشته شده‌اند. API پولی OpenAI استفاده نمی‌شود و توکن ChatGPT/Codex برای ASR خرج نمی‌شود.

## استقرار خودکار

هر push به main → تست‌ها → Liara CLI → بررسی SHA همان commit روی /health.

یک بار باید کلید موجود لیارا در Settings → Secrets and variables → Actions با نام `LIARA_API_TOKEN` ذخیره شود. کلید وارد کد یا history گیت نمی‌شود. تا قبل از این تنظیم، تست‌ها اجرا می‌شوند و مرحلهٔ استقرار صریحاً «پیکربندی نشده» اعلام می‌شود.

توکن بله و ورود Codex روی محیط/دیسک موجود لیارا باقی می‌مانند. دیسک archive و مسیر /usr/src/app/data در liara.json حفظ شده‌اند. باینری Codex و Whisper روی دیسک دائمی هستند و در مخزن قرار نمی‌گیرند. این workflow برنامهٔ موجود را به‌روزرسانی می‌کند؛ برای یک سرور کاملاً تازه، runtimeها و ورود Codex یک‌بار باید آماده شوند.

`python main.py` ورودی عملیاتی است. مسیر مستقل قدیمی `python -m hamdel` را هم‌زمان اجرا نکن. تنها یک replica باید پیام‌ها را دریافت کند.

## توسعه

`python -m unittest discover -s tests -v`

برای اجرای محلی، وابستگی‌ها را از requirements.txt نصب و BALE_BOT_TOKEN را فقط در محیط امن تنظیم کن. data، رسانه‌ها، sessionها و auth هرگز commit نمی‌شوند. خروجی ایجنت فقط از outputs، با پسوند و حجم مجاز ارسال می‌شود. ثبت مالی قطعی خارج workspace ایجنت قرار دارد.
