# بات گزارش همدل (تلگرام + Claude)

گزارش‌های همدل (متن، ویس، عکس، فیلم) را می‌گیرد، ویس فارسی محاوره‌ای را به متن می‌برد، با Claude خلاصه و دسته‌بندی می‌کند و در چت خصوصی مدیر همراه با عکس و فیلم مرتبط می‌فرستد.

## جریان کار
1. مدیر ویس، عکس، فیلم یا پیام فورواردشده را در چت خصوصی بات می‌فرستد؛ یا بات در یک گروه تلگرامی است و پیام‌های آن گروه را می‌گیرد (اختیاری: با `REPORT_SENDER` فقط یک `@username` پذیرفته می‌شود).
2. وقتی ۲ دقیقه پیام تازه نیاید، پیام‌های جمع‌شده یک «گزارش» می‌شوند.
3. ویس/ویدیو → Gemini (فارسی، پیش‌فرض) یا Cloudflare Whisper → متن خام (ذخیره می‌شود) → Claude متن را روان‌سازی می‌کند. اگر عدد یا حجم متن تغییر کند، متن خام نشان داده می‌شود.
4. عکس‌ها و چند فریم از ویدیو را Claude می‌بیند. خروجی: عنوان، دسته، خلاصه، نکته‌ها، مبلغ‌های ذکرشده (تأییدنشده)، پیگیری‌ها، موارد نیازمند بررسی.
5. در خصوصی مدیر: پیام خلاصه، متن کامل هر ویس، و فقط عکس/فیلم‌های مرتبط (فایل‌هایی که Claude ندیده هم فرستاده می‌شوند).
6. هر متن ساده‌ای که مدیر در خصوصی بنویسد، با تکیه بر گزارش‌های اخیر جواب داده می‌شود.

دسته‌ها با `HAMDEL_CATEGORIES="الف|ب|ج"` عوض می‌شوند. این بات دفتر مالی و تأیید ثبت ندارد؛ مبلغ‌ها فقط گزارش می‌شوند.

## راه‌اندازی
راهنمای کامل در `DEPLOY.md`. خلاصه: در تلگرام با @BotFather بات بساز؛ اگر بات در گروه است `/setprivacy` را Disable کن؛ متغیرهای `.env.example` را بگذار؛ `/whoami` را بفرست و `OWNER_ID` (و برای گروه `GROUP_CHAT_ID`) را تنظیم کن؛ `python main.py` (پایتون ۳٫۱۲ و ffmpeg). تست: `python -m unittest discover -s tests`.

## مغز بات و هزینه
پیش‌فرض `LLM_PROVIDER=claudecode`: Claude Code روی سرور با اشتراک Claude خودت (`claude setup-token`)، بدون API پولی. گزینه‌ها: `cloudflare` (رایگان، ضعیف‌تر) و `claude` (کلید API پولی).
تبدیل ویس: اگر `GEMINI_API_KEY` باشد Gemini، وگرنه Cloudflare Whisper.

## آنچه تست نشده
تست‌ها با Telegram، Cloudflare و Claude ساختگی‌اند؛ دستورهای ffmpeg روی فایل واقعی آزمایش شدند. کیفیت فارسی مدل‌های رایگان، تشخیص گفتار محاوره‌ای روی ویس واقعی، قالب پاسخ مدل‌های Cloudflare (متن و بینایی) و پارامترهای Whisper هنوز آزمایش نشده است.

## Deploy status
